# NIST AI RMF 1.0 and the Generative AI Profile: Themis control mapping

Sources, retrieved 2026-10-11:

- NIST AI Risk Management Framework 1.0 (NIST AI 100-1, released 2023-01-26), https://www.nist.gov/itl/ai-risk-management-framework, document https://doi.org/10.6028/NIST.AI.100-1. The four core functions are Govern, Map, Measure and Manage.
- NIST AI 600-1, Artificial Intelligence Risk Management Framework: Generative AI Profile (released 2024-07-26), https://doi.org/10.6028/NIST.AI.600-1, read from https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.600-1.pdf. Action IDs below are copied from its Appendix A suggested-action tables, where GV, MP, MS and MG tag the Govern, Map, Measure and Manage functions.

This is an informational mapping, not a certification. NIST publishes the AI RMF as voluntary guidance with no certification scheme, and nothing here claims conformance. The "Themis control" column is about what Themis implements; the action text is paraphrased in the "Risk" column and the full wording is in the profile. Many suggested actions are organisational (policies, training, incident teams) and can only be met by the organisation running the tools, so they are marked `GAP` for the code.

Paths are relative to `packages/` unless they start with `docs/` or `scripts/`.

| ID | Risk | Themis control | Code path (file:symbol) | Test | Residual / gap |
